Напиши спеку фичи «купоны» в docs/specs/coupons/. Ответы на вопросы сразу: купон — фиксированная скидка в центах; применяется после процентной скидки; итог не может быть меньше 0 (тогда 0); на заказ максимум один купон; купоны с истёкшим сроком отклоняются ошибкой ErrCouponExpired; хранение купонов и UI — вне scope, сейчас только функция расчёта в пакете pricing. Вопросов больше не задавай.
